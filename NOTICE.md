# CDOMKA Typist Notices

This is a simplified offline typing challenge inspired by Monkeytype.

Reference project: https://github.com/monkeytypegame/monkeytype

Monkeytype is licensed under GPL-3.0. This local version uses Monkeytype-derived English quote data, plus a similar visual style, mode structure, typing feedback pattern, and theme-variable approach, but is a standalone HTML/CSS/JS adaptation for offline expo use.
